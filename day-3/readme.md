# 🚀 Backend Development Journey — Day 3

## Creating My First Notes API

Welcome to **Day 3 of my Backend Development Journey!** 👨‍💻

Today, I built my first simple **Notes API** using Node.js.

In this practice project, I learned how a client can **send data to a server using a POST request**, how the server receives that data, and how the data can be stored in an array.

I also created a **GET API** to retrieve the saved notes from the server.

This was my first practical experience of sending and receiving data through APIs. 🚀

---

## 📅 Day 3 — What I Learned

Today I learned:

- How to create a `POST` API
- How to send data using Postman
- How to send data in `raw / JSON` format
- How the server receives data from `req.body`
- How to store received data inside an array
- How to create a `GET` API
- How to retrieve data from the server
- Basic understanding of client-server communication
